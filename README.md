# ERP GlassOS

ERP GlassOS is a modern, privacy-first ERP companion dashboard built with Next.js, TypeScript, TailwindCSS, Framer Motion, and Recharts.

The project is designed to provide students with a clean, fast, and visually appealing way to view ERP information such as homework, circulars, attachments, timetables, analytics, and exports.

---

## Features

### Dashboard

- Homework Overview
- Circular Overview
- Pending Tasks
- Completed Tasks
- Attachment Statistics
- Recent Upload Activity

### Homework

- Subject Tracking
- Homework Status
- Description Viewer
- Attachment Detection
- Upload Timestamp Recovery

### Circulars

- Circular List
- Attachments
- Category Tracking
- Search and Filtering

### Timetable

- Daily Timetable
- Weekly Timetable
- Exam Timetable

### Analytics

- Subject Activity
- Homework Trends
- Upload Activity
- Monthly Statistics

### Attachment Explorer

- PDF Files
- DOCX Files
- Images
- Attachment Metadata
- Timestamp Recovery

### Export Center

Export Data As:

- CSV
- Excel (XLSX)
- JSON
- PDF

### Developer Panel

Provides:

- Request Logs
- Parser Logs
- Timestamp Recovery Logs
- Export Logs
- System Status
